# 📱 Personal Budget App (iOS & Laptop Responsive)

Aplicación web y móvil de presupuesto personal con diseño moderno en azul oscuro y blanco, con backend en Node.js/Express, gráficos de distribución y análisis de evolución de gastos evitables.

## 🚀 Características

- 📱 **Diseño UI iPhone 16 Pro & Adaptable a Laptop**: Interfaz orgánica con cambio de vista (Móvil vs Escritorio).
- 💰 **Sueldo Mensual Editable**: Edición rápida con recálculo en tiempo real de salarios y categorías.
- ⚡ **Gastos Evitables & Curva de Ahorro**: Identificación de gastos prescindibles y gráfico de proyección acumulada (hasta S/. 3,480+ al año).
- 📈 **Inversión al 10% Dinámica**: Cálculo automático de porcentaje del sueldo.
- 🖥️ **Backend REST API**: Servidor Express con persistencia en base de datos JSON local.

## 🛠️ Instalación y Uso Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar el servidor
npm start
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🌐 Despliegue en la Nube (Acceso desde cualquier dispositivo)

1. Sube este repositorio a tu cuenta de **GitHub**.
2. Conecta el repositorio en [Render.com](https://render.com) o [Railway.app](https://railway.app) (Plan Gratuito Web Service).
3. Configura el comando de inicio: `node server.js` o `npm start`.
4. ¡Listo! Obtendrás un enlace HTTPS público accesible desde cualquier celular o computadora.
